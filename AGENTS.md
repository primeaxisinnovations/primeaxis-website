# PrimeAxis Platform — Agent Brief

## What this project is
PrimeAxis is Africa's maritime intelligence and strategic communications platform.
Not a news blog. An authority platform — think Lloyd's List, Splash247, Seatrade Maritime,
interpreted for the African maritime and blue economy space.

## Brand
- Platform name: PrimeAxis
- Full company name: PrimeAxis Innovations Limited
- Primary blue: #485778
- Gold accent: #BF9F66
- Deep background: #151C2E
- Headline font: Playfair Display (Google Font)
- UI font: Montserrat (Google Font)
- Tone: authoritative, editorial, premium, Africa-first

## Pages to build (Phase 1)
1. Homepage — authority statement, featured intelligence, executive conversations,
   services snapshot, partnership strip, newsletter signup
2. About — vision, mission, founder positioning
3. Insights — article listing grid with beat/category filters
4. Single article — full editorial article layout
5. Executive Conversations — interview series hub
6. Media Hub — video gallery
7. Services — outcome-framed service descriptions with inquiry CTAs
8. Work With Us — partnerships, sponsorships, collaborations
9. Contact — segmented by inquiry type

## Design reference
A fully designed homepage HTML file is in the project root: primeaxis_homepage.html
Use it as the definitive design reference for colors, layout, typography, and content structure.

## Tech rules
- TypeScript throughout — no plain JS files
- Tailwind CSS for all styling
- App Router file structure
- Mobile-first responsive design
- No external UI libraries — build everything custom to match the design
- Google Fonts loaded via next/font

## Content rule
All placeholder content must sound like real PrimeAxis content —
maritime industry-specific, Africa-focused, executive-level language.
No lorem ipsum anywhere.
